# Totem Lumen 0.1.0-alpha.65

Minecraft 26.3 · Fabric · Java 25

- Minecraft RGB now matches vanilla Overworld daylight more closely. Morning and late-afternoon sunlight no longer gives outdoor surfaces a pronounced blue cast, and shade under overhangs follows vanilla brightness more closely.
- Daylight shading uses Minecraft's sky color, weather-dependent light level and brightness setting. Twilight blends into the existing RGB night lighting.
