# Totem Lumen 0.1.1-beta.3

Minecraft 26.3 · Fabric · Java 25

- Lumia now renders reflections and refraction on vanilla glass blocks and panes. Reflections strengthen at grazing angles, and thin panes bend the view less than full blocks.
- Stained glass filters direct light by colour, so a lamp shining through red glass can cast red light onto the floor.
- Refraction samples the visible opaque scene. Overlapping transparent surfaces are approximate.
- Tested both classic transparency and improved transparency (OIT) in game on Linux with an NVIDIA RTX 5060 Ti. Windows and macOS passed shader pipeline checks.
