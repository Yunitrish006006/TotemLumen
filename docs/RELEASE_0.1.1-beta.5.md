# Totem Lumen 0.1.1-beta.5

Minecraft 26.3 · Fabric · Java 25

- With beta rendering enabled, Lumia prepares its graphics pipelines in the background. You can enter a world and keep playing on your current render profile. Video Settings shows when Lumia is ready to select, and the profile shortcut skips it while preparation is in progress.
- If Lumia is your saved profile, the world initially renders with Minecraft Pure and automatically returns to Lumia once preparation finishes.
- Low shadow quality now uses fewer daylight samples. Turning off reflections or local lights also removes that work from the Lumia shader.
- Tested both manual selection and automatic restoration on Linux with an NVIDIA RTX 5060 Ti. Windows and macOS passed shader pipeline checks.
