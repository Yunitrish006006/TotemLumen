# Totem Lumen 0.1.0-alpha.75

Minecraft 26.3 · Fabric · Java 25

- Minecraft RGB prepares lighting ahead of the player while exploring. Nearby fire and soul fire get an early lighting pass so the surrounding Nether terrain can appear lit on its first visible frame.
- Added an unbound lighting profile shortcut in Controls. Hold the assigned key and scroll up or down to switch profiles. The current profile appears above the hotbar and is saved.
- Video Settings now shows Pure Minecraft and Minecraft RGB by default. Turn on **Use Beta Rendering Methods** to also select Totem Lumen or Raster Ray. Turning it off while using a beta profile switches to Minecraft RGB. Existing beta selections also start in Minecraft RGB until you opt in.
