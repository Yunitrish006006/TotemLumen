# Totem Lumen 0.1.0-alpha.62

Minecraft 26.3 · Fabric · Java 25

- Minecraft Pure now uses vanilla terrain lighting when you or another player holds a torch, lantern or other light source.
- In Minecraft RGB, overlapping hand lights now keep the strongest contribution in each color channel. Two identical torches at the same position light a wall as brightly as one. Different colors can still mix.
- The bundled default lighting pack now uses 1× brightness for a smoother gradient around placed lights. Custom packs can select their own multiplier.

Raster Ray and the full Vulkan renderer remain experimental.
