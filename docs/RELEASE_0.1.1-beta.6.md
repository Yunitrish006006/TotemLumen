# Totem Lumen 0.1.1-beta.6

Minecraft 26.3 · Fabric · Java 25

- With beta rendering enabled, Totem Lumen, Raster Ray and Lumia each prepare in the background. Video Settings shows when each profile is ready, and the profile shortcut skips those still compiling. Minecraft Vanilla and RGB remain available.
- If a saved profile is still preparing when you enter a world, Minecraft Vanilla displays the world until that profile is ready. Switching into Totem Lumen now loads nearby chunks first so the terrain in front of you appears sooner.
- Lumia now exposes **World reflections** in Video Settings and preserves your previous setting. Turn it on to see nearby colours reflected in iron, gold and copper while keeping the original texture visible.
- All five profiles were exercised in-game on Linux with an RTX 5060 Ti. Windows and macOS passed shader pipeline checks.
