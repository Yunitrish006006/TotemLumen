# Totem Lumen 0.1.0-alpha.66

Minecraft 26.3 · Fabric · Java 25

- Ordinary torches cast slightly brighter warm light in Minecraft RGB. In a dark-room test, the same stone floor was about 4% brighter with a held torch and 3.7% brighter with a placed torch.
- The adjustment also applies to similarly colored mixed light. Torch range, daylight and mob spawning retain their existing behavior.
