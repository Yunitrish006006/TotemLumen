# Totem Lumen 0.1.1-beta.4

Minecraft 26.3 · Fabric · Java 25

- In Lumia, iron, gold and copper reflect nearby blocks and the sky while their original texture and seams remain visible. Oxidized copper has a weaker reflection.
- Sun shadows now have softer edges, and daylight reaches under overhangs from the sides. This smooths the transition from sunlit ground to shade while keeping the block textures sharp.
- Tested in game on Linux with an NVIDIA RTX 5060 Ti. Windows and macOS passed shader pipeline checks. The frame-rate impact of the additional daylight samples has yet to be measured.
