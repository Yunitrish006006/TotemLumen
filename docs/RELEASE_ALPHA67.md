# Totem Lumen 0.1.0-alpha.67

Minecraft 26.3 · Fabric · Java 25

- Lit furnaces now cast the same warm orange light as ordinary torches. Glow lichen casts a soft lake-green light.
- Minecraft RGB raises ambient light in the Nether so surfaces are easier to see away from light sources.
- Minecraft RGB skips redundant lighting lookups when shading terrain. In a Nether test scene, median CPU shading time per terrain quad fell from 1.89 to 1.63 microseconds.
