# Totem Lumen 0.1.0-alpha.77

Minecraft 26.3 · Fabric · Java 25

- Blocks without a configured light color now cast a color sampled from their original textures. Crying obsidian, for example, casts purple light on nearby surfaces.
- The average accounts for visible model face area, pixel opacity and animation frame duration. Existing color overrides and block light levels keep their priority.
- The mod includes precomputed colors for 109 vanilla emitters, so clients and dedicated servers can use the same palette while exploring.
