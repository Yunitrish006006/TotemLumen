# Totem Lumen 0.1.0-alpha.73

Minecraft 26.3 · Fabric · Java 25

- In the Minecraft RGB profile, Nether light scans now start near the player's height and give nearby fire, soul fire, and magma blocks an early pass. This helps their light reach nearby surfaces sooner when entering an area.
- Newly loaded terrain can still take additional time to appear after its light has been calculated.
