# Totem Lumen 0.1.0-alpha.63

Minecraft 26.3 · Fabric · Java 25

- Minecraft RGB now uses the same light propagation and occlusion for held and placed light sources. Overlapping lights use the strongest contribution in each RGB channel.
- Players, mobs, armor and first-person arms now receive light from this same RGB field.
- Held lights remain visual only and do not affect mob spawning. Minecraft Pure keeps held lighting disabled.
