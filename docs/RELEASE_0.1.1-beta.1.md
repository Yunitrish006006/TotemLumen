# Totem Lumen 0.1.1-beta.1

Minecraft 26.3 · Fabric · Java 25

- Added **Lumia**, a fifth rendering profile. Enable **Use Beta Rendering Methods** in Video Settings, then choose **Lumia** under **Quality & Performance**.
- Minecraft draws the original models and textures. Lumia shades terrain, entities, held items, clouds and precipitation with Vulkan. Nearby RGB emitters cast shadows and light surrounding surfaces. Reflections approximate nearby block colours, and moving creatures cast simplified shadows.
- Lumia passed shader pipeline checks on Windows and macOS. In-game lighting and precipitation were tested on Linux with an NVIDIA RTX 5060 Ti. Windows and Apple Silicon gameplay performance still needs hardware testing.
