# Totem Lumen 0.1.0

Minecraft 26.3 · Fabric · Java 25

- Lit blast furnaces and smokers now cast the same warm light as a regular furnace. All three stop emitting light when idle.
- Minecraft RGB preloads nearby emissive blocks and uses original texture colors when a block has no configured light color.
- Pure Minecraft and Minecraft RGB are the default profile choices. Totem Lumen and Raster Ray remain opt-in beta rendering methods under Video Settings.
